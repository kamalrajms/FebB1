## react intro

    What is React?

    1) React is a JavaScript library (not a framework) developed by Facebook (Meta) for building user interfaces (UIs), especially Single Page Applications (SPAs).

    2) It helps developers build reusable UI components that update efficiently when data changes.

    Instead of reloading a whole webpage when something changes, React updates only the parts of the UI that need to change.

    -------
    Why do we need React?

	It makes UI development faster, cleaner, and more efficient.

	Provides a better user experience with smooth updates without page reloads.

## useState()and Forms and Controlled inputs

    useState is a react hook that allows you to add state (data that can change over time)
    to a functionl component.

    Normally ,in js functions, variables disappear after the function runs.
    But with useState ,react remembers values between re-renders.

    syntax:

        const[state,setState]=useState(initialValue)

        state-- the current value of the variables
        setState--- a function that update the state
        initialValue--- the starting value of the state.

## useCallback()

    useCallback is a react hook used to  memoize  (store) a function so that react Does not recreate
    the function on every render unless dependency changes .

    it is mainly used for performance optimization in rect Applications.

    Every time a component re-renders,
    it create a brand-new copy of Every function inside it.

    Every if the function's code looks exactly the same,
    React  sees it as different because it's new object in memory.

    syntax:

        const name=useCallback(()=>{
            // code...
        },[dependency,dependency2...])

## Routoing in react and nested routing

    Routing means navigation between diffetent page in a web app without refreshing
    the browser.

    In traditional website .clicking a link reloads the whole page.

    In react SAP ,Routing lets us changes the view without   reloading.


            better performance (ni full page reload)
            Smooth user experiance
            Control over navigation without server request



    commend :npm install react-router-dom

    Structure:

        <BrowserRouter>
        <Routes>
        <Route path="We need to add address path for a component" elemant={<component/>}/>
        <Route path="home" elemant={<Home/>}/>
        <Route path="about" elemant={<About/>}/>
        <Route path="service" elemant={<Service/>}/>
        </Routes>
        </BrowserRouter>


        BrowserRouter:

            it is   the main wrapper component for routing in react app.
            it enables navigation using browser URL (history API)
            Without this,  routing will not work.

        Routers  
            it contains all the  <Route/> component
            It tells react which component to show at a for which path
            Only one route will match and render at a time

        Route

            Defins a specific URL Path andWhich component should load for that path.
